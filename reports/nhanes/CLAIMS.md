Built ML model flagging early CKD from 17 routine blood tests + 2 self-built kidney scores; 39K adults, 0.86 AUC; 0.64 AUC on 399 hospital patients

## Wording the results do not fully support

1. **"early CKD" next to 0.86.** The 0.86 AUC is for all-stage CKD (eGFR < 60 OR ACR >= 30),
   and eGFR is both a feature and half of that label, so part of the 0.86 is definitional.
   The measured early-stage performance (test participants with eGFR >= 60, where CKD can only be
   albuminuria) is **0.75 AUC [0.73, 0.77]**: real signal, clearly above the
   eGFR-only baseline (0.56), but moderate. "Early" is justified only if the 0.75 is the
   number next to it. Quoting 0.86 as an "early CKD" result is an overstatement.
2. **"0.64 AUC on 399 hospital patients"** is accurate but is a weak result (CI 0.59-0.70),
   and it is the 14-feature logistic model, not the 0.86 model, that was transferred. Post-hoc
   diagnostics show the gap comes from standardised missing-value indicators (AUC 0.98 on the 212
   patients with complete labs), but that analysis is exploratory and **must not be cited as the
   external result**. Either quote 0.64 as what it is (a transfer gap you found and diagnosed) or
   leave the external claim out of a 150-character line and discuss it in the essay.
3. **"self-built kidney scores."** eGFR and the BUN:creatinine ratio are standard clinical
   formulas that you implemented and validated, not scores you invented. "Derived" or
   "computed" kidney scores is accurate; "self-built" invites the reading that you designed them.
4. **"routine blood tests"** is supported: all 17 analytes come from a standard metabolic panel,
   a CBC and an HbA1c. Saying "17 blood tests" rather than "3 panels" is defensible because they
   are 17 distinct measured analytes, but "3 routine blood panels" is the more conservative phrasing.
5. **"39K adults"**: say "39K US adults" if space allows; the data are a US national survey.

## Honest alternative lines (all <= 150 characters)

```
Built ML model flagging CKD from 17 routine blood tests + 2 derived kidney scores; 39K US adults, 0.86 AUC (0.75 early-stage, no urine test)
```
140 characters. Leads with the all-stage AUC and names the early-stage number explicitly.

```
Built CKD screening model from 17 routine blood tests + 2 derived kidney scores; 39K US adults (CDC NHANES), 0.86 held-out AUC, 0.75 early-stage
```
144 characters. Names the data source; no external claim.

```
Built ML model flagging CKD from 17 routine blood tests; 39K US adults, 0.86 AUC (0.75 early-stage); external test on 399 patients: 0.64
```
136 characters. Keeps the external number as a reported finding rather than a selling point.

## Recommended line

```
Built ML model flagging CKD from 17 routine blood tests + 2 derived kidney scores; 39K US adults, 0.86 AUC (0.75 early-stage, no urine test)
```
**140 characters.** It is the strongest line every number in this repo supports without
qualification; the 0.64 external result and its diagnosis belong in the additional-information
or essay section, where the transfer gap can be framed as something you found, diagnosed and
documented rather than hidden.
